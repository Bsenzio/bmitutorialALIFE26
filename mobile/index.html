About the Tutorial

This tutorial introduces the fundamentals of Brain–Machine Interfaces (BMI) and Brain–Computer Interfaces (BCI), combining neural signal processing, machine learning, Artificial Life, and interactive systems through practical demonstrations and open-source tools.

Tutorial Highlights

  • Brain–Computer Interfaces (BCI)
  • EEG acquisition and signal processing
  • Machine Learning pipelines
  • Artificial Life interactive systems
  • Hands-on demonstrations
  • Open-source software and educational resources
